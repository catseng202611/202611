# 3.1.1 HTML 實作教材

教材依《3.1 網頁技術基礎_HTML入門》整理。對照表頁碼從簡報封面起算。

## 開始使用

1. 在 VS Code 選擇「檔案 → 開啟資料夾」，開啟「3.1.1 HTML」。
2. 在擴充功能中安裝 Live Server。右鍵點選想預覽的 HTML 檔案，選擇 **Open with Live Server**。
3. 先開啟 **Example**，對照程式碼與瀏覽器畫面，再打開對應的 **Practice**，閱讀原始碼中的題目註解，在指定位置自行實作。儲存後回到瀏覽器觀察結果。
4. 題目指定另建或修改 hello.html、img.html、text.html、style.css 或 app.js 時，請在自己的練習資料夾操作。需要測試相對路徑時，把題目用到的檔案放在同一個練習資料夾，並從該資料夾啟動 Live Server。
