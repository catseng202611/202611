# Git

## 下載與安裝

1. Windows
   - [Git 官方網站](https://git-scm.com/) → Download for Windows
   - 安裝時建議選擇 VS Code 作為預設編輯器
   - `git --version`
2. macOS
   - Xcode Command Line Tools：`xcode-select --install`
   - 或 Homebrew：`brew install git`
   - 升級：`brew upgrade git`（僅適用 Homebrew 安裝版本）
   - `git --version`
3. Ubuntu / Kali Linux
   - `sudo apt update`
   - `sudo apt install git`
   - `git --version`

## 複製專案（Clone）

- `git clone [URL]` 複製遠端儲存庫
- `git clone https://github.com/catseng202611/202611.git`

## 設定個人資訊

- `--global`：全域設定，適用於目前使用者的所有 Git 專案
- 不加 `--global`：設定目前儲存庫
- `user.name`：Commit 作者名稱
- `user.email`：Commit 作者 Email

1. `git config --global user.name "UserName"`
2. `git config --global user.email "Email@example.com"`
3. `git config --list` 確認設定

## 例外 `.gitignore`

```gitignore
# 忽略備份檔案
*.bak

# 忽略所有 .log 檔案
*.log

# 忽略 node_modules 資料夾
node_modules/

# 忽略 macOS 系統檔
.DS_Store

# 忽略機密環境檔
.env
.env.*
```

> `.gitignore` 主要對尚未被 Git 追蹤的檔案生效，已提交的檔案不會自動停止追蹤。

## 初始化

- `git init`
- 產生 `.git` 隱藏資料夾，用來保存 Git 版本紀錄

## 存檔

- `git status` 查看修改狀態
- `git add .` 暫存目前目錄下的修改
- `git add [filename]` 暫存指定檔案
- `git commit -m "這裡寫你的提交訊息"` 建立本機版本

## 雲端同步

- 設定遠端：`git remote add origin [URL]`
- 首次上傳：`git push -u origin main`（假設主要分支為 main）
- 後續上傳：`git push`
- 下載更新：`git pull`
- 取得遠端資訊：`git fetch`
- `git pull` = `git fetch` + Merge 或 Rebase（依 Git 設定）

## 分支管理與備份

- `git branch` 查看目前分支
- `git switch -c backup-20261112` 建立並切換至新分支（作為版本備份）
- `git add .`
- `git commit -m "備份20261112"`
- `git push -u origin backup-20261112` 將備份分支上傳 GitHub

> 本機分支不等於遠端備份，需要 Push 才會同步到 GitHub。

## 強制覆蓋本機分支

- `git status` 確認目前修改
- `git switch main` 切換回 main 分支
- `git fetch origin` 取得遠端最新狀態（不會直接修改本機工作檔案）
- `git reset --hard origin/main` 將本機 main 強制重設為遠端 main 的版本

> [!WARNING]
> **注意資料遺失風險**
>
> `git reset --hard` 會捨棄已追蹤檔案的未提交修改，並使本機 main 不再保留未推送提交作為分支歷史的一部分。一般未追蹤檔案不會被刪除，但可能被覆蓋路徑上的檔案例外。執行前請先備份重要資料。

> [!TIP]
> **為什麼不用 `git pull`？**
>
> `git pull` 會取得並整合遠端修改。如果本機與遠端產生衝突，可能需要手動處理。
>
> 若目標是「捨棄本機修改，將 main 重設為遠端版本」，可使用 `git fetch origin` 搭配 `git reset --hard origin/main`。
