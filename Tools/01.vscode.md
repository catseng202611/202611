# Visual Studio Code（VS Code）

Visual Studio Code 是 Microsoft 提供的免費程式碼編輯器，支援 Windows、macOS 與 Linux，並可透過擴充套件增加開發功能。

本課程以 **VS Code 為主要開發工具**，搭配 GitHub Copilot AI，學習 HTML、CSS、JavaScript 及後續伺服器端程式設計。

## 一、下載與安裝

官方網站：https://code.visualstudio.com/

### 1. Windows（主要示範）

1. 前往官方網站下載 Windows 安裝程式。
2. 執行安裝程式，建議勾選：
   - `Add to PATH`：可在終端機使用 `code` 指令。
   - `Open with Code`（檔案）：在檔案上按右鍵，可使用 VS Code 開啟。
   - `Open with Code`（目錄）：在資料夾上按右鍵，可使用 VS Code 開啟整個專案。
3. 完成安裝並啟動 VS Code。

> 建議保留其他預設選項。安裝完成後若 `code` 指令無法使用，請重新開啟終端機。

### 2. macOS（Intel / Apple Silicon）

1. 前往官方網站下載 macOS 版本。
   - Intel Mac：選擇 Intel。
   - M1、M2、M3、M4 等：選擇 Apple Silicon。
   - Universal：同時支援 Intel 與 Apple Silicon。
2. 開啟下載的 `.dmg`，將 `Visual Studio Code.app` 拖曳至「應用程式」（Applications）資料夾。
3. 啟動 VS Code。
4. 按下 `Cmd + Shift + P` 開啟命令選擇區（Command Palette）。
5. 輸入 `shell command`，選擇 `Shell Command: Install 'code' command in PATH` 或對應的新版命令。
6. 重新開啟 Terminal。

完成後，可在終端機使用：

```bash
code .
```

此指令會使用 VS Code 開啟目前所在的資料夾。

### 3. Ubuntu / Kali Linux（AMD64 / ARM64）

1. 前往官方網站下載 Linux `.deb` 安裝套件。
   - Intel / AMD：選擇 x64（AMD64）。
   - ARM64：選擇 ARM64。
2. 開啟終端機，進入下載檔案所在資料夾。
3. 執行安裝指令：

```bash
sudo apt install ./code_*.deb
```

4. 安裝完成後啟動 VS Code：

```bash
code
```

> 使用 `apt install ./檔案名稱.deb` 可以同時處理可取得的套件相依性。以上指令適用於目前資料夾只有一個符合 `code_*.deb` 的安裝檔時。

## 二、安裝擴充套件（Extensions）

點選 VS Code 左側的「擴充功能」（Extensions），或按下：

- Windows / Linux：`Ctrl + Shift + X`
- macOS：`Cmd + Shift + X`

搜尋套件名稱，點選 **Install（安裝）**。

### 1. 基礎環境（推薦）

**Chinese (Traditional) Language Pack for Visual Studio Code**
- 提供繁體中文操作介面。
- 安裝後依提示重新啟動或切換顯示語言。

**Live Preview（推薦）**
- Microsoft 提供的網頁預覽擴充套件。
- 可在 VS Code 內預覽 HTML 網頁。
- 支援修改後自動更新預覽畫面。
- 適合 HTML、CSS、JavaScript 入門練習。

**Live Server（替代方案）**
- 啟動本機 HTTP 伺服器，使用瀏覽器預覽網頁。
- 修改檔案後可自動重新整理。
- 與 Live Preview 擇一安裝即可。

> Live Preview / Live Server 主要用於前端靜態網頁。PHP、Python 等伺服器端程式，需要另外建置對應執行環境。

### 2. 程式編輯輔助（選用）

**HTML CSS Support**
- 提供 HTML 中的 CSS Class、ID 等相關提示。
- 適合學習 HTML 與 CSS 的關聯。

**Prettier - Code formatter**
- 自動整理 HTML、CSS、JavaScript 的程式碼格式。
- 統一縮排與排版風格。
- 可依需求設定存檔時自動格式化。

**Material Icon Theme**
- 依檔案類型顯示不同圖示。
- 方便辨識 HTML、CSS、JavaScript 等檔案。

**Auto Rename Tag**
- 修改 HTML 開始標籤時，可同步修改結束標籤。
- VS Code 已內建部分相關功能，可視需要安裝。

### 3. 進階開發工具（後續課程選用）

**ESLint**
- JavaScript 程式碼品質與規則檢查。
- 適合開始建立較完整的 JavaScript 專案後使用。

**Live Share**
- 支援多人共同編輯與遠端協作。
- 可用於小組專案或協助除錯。

**Markdown All in One**
- 提供 Markdown 編輯、快捷鍵及預覽輔助。
- 適合編寫 `README.md` 與專案說明文件。

**Git History**
- 輔助查閱 Git 版本修改歷程。
- 初學階段可先使用 VS Code 內建的 Source Control。

> VS Code 已內建 HTML、CSS、JavaScript 的基本語法提示，以及 Git 版本管理功能，不需要另外安裝基本語法套件。

## 三、啟用 AI 開發功能

### 1. GitHub Copilot（Copilot Free，推薦）

1. 啟動 VS Code。
2. 點選 Copilot 圖示，選擇 `Use AI Features`。
3. 使用 GitHub 帳號登入並完成授權。
4. 符合資格且尚未訂閱者，可啟用 Copilot Free。
5. 開啟 AI Chat，測試對話及程式碼說明功能。

**主要用途**
- 解釋 HTML、CSS、JavaScript 語法。
- 協助了解錯誤訊息。
- 提供程式碼修改建議。
- 產生簡單範例，輔助練習。

> Copilot Free 有使用額度限制，實際可用模型及額度以 GitHub 官方公告為準。

### 2. Google Antigravity（選用）

- 可安裝 Antigravity IDE，或在 VS Code 安裝 Antigravity Extension（擴充套件）。
- 使用 Google 帳號登入。
- 可作為 GitHub Copilot 以外的 AI 開發工具。
- 本課程不另外示範 Antigravity IDE。

## 四、安裝完成後檢查

請確認以下項目：

- [ ] VS Code 可以正常啟動。
- [ ] 已設定繁體中文介面。
- [ ] 已安裝 Live Preview 或 Live Server。
- [ ] GitHub Copilot 可以正常使用。
- [ ] 可以使用 VS Code 建立及開啟資料夾。
- [ ] 可以建立、編輯與儲存檔案。

## 五、記住

1. **VS Code 是開發工具**，不是所有程式的執行環境。
2. **擴充套件依需求安裝**，不是裝得越多越好。
3. **AI 是輔助學習工具**，必須理解產生的程式碼。
4. **注意開源授權**，使用第三方套件時應遵守授權條款。
5. 後續進入伺服器端程式設計時，將介紹 **VS Code + Remote SSH**，連接 Linux 伺服器進行開發。
